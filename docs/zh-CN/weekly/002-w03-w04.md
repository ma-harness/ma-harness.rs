## 本周关键产出 (5 份代码模块)

### 1. ma_harness_proto (Day 11-12) — Protobuf wire 格式

| 文件 | 行数 | 内容 |
|---|---|---|
| `Cargo.toml` | 30 | 加 tonic-build (build) + tonic / prost / prost-types (deps) + chrono / serde_json / ma_harness_core (convert) |
| `build.rs` | 30 | tonic_build::configure 编 3 个 .proto, 输出到 OUT_DIR |
| `src/lib.rs` | 200 | `pub mod ma_harness::v1 { tonic::include_proto!("ma_harness.v1"); }` + convert module (proto ↔ core) + 3 测试 |

**关键设计**:
- proto 是 wire 格式, core 是 runtime 强类型, 两层分离
- convert 函数: `session_event_from_proto` / `session_event_to_proto`
- 未知 i32 fallback (event_type=9999 → Unspecified, severity=9999 → Info)
- OUT_DIR 生成代码不进 git (兼容 .gitignore)

### 2. ma_harness_seam (Day 13-14) — 公开抽象层

| 文件 | 行数 | 内容 |
|---|---|---|
| `Cargo.toml` | 25 | 加 ma_harness_cordis / ma_harness_plugin_macro / ma_harness_core (path) + anyhow / async-trait / serde / serde_json / futures |
| `src/lib.rs` | 340 | 5 公开 trait + 5 macro re-export + 2 包装 (CordisService/CordisPlugin) + PluginRegistry + PluginLoader stub + 4 测试 |

**5 公开 trait** (跟 cordis 内部 trait 独立):
- `Service` (type Ctx = Context, type Error)
- `Plugin` (install / name / uninstall)
- `Listener` (blanket impl Fn, 同 cordis)
- `Disposable` (dispose)
- `Tool` (name/description/schema/invoke async via BoxFuture)

**CordisService<S> / CordisPlugin<P>**: 包装公开 trait 成内部 trait, 业务方写 seam 跟 ctx 内部 cordis 都自动满足。

### 3. hello plugin 重写 (Day 15) — seam 风格 demo

- HelloService / HelloPlugin **双重 impl** (cordis + seam), 方法签名同
- typed key `GREETING_TEMPLATE` 用 `seam::ctx_key!` (re-export)
- 5 个单元测试 (用 seam::PluginRegistry 装载)

### 4. 6 个 first-party 插件骨架升级 (Day 16-17) — 统一模板

通过 `gen_plugins.py` 脚本生成 6 个 lib.rs, 100% 一致格式:
- **bash**: MAX_RUNTIME_MS
- **fs**: READ_ALLOW_LIST / WRITE_ALLOW_LIST
- **web**: EGRESS_ALLOW_LIST / TIMEOUT_MS
- **subagent**: MAX_DEPTH
- **skill**: SKILLS_DIR
- **cordis**: INSPECT_DEPTH

每个 plugin: 双重 impl (cordis + seam), typed key 1-2 个, Week 5-6 实装业务逻辑。

### 5. ma_harness_server + ma_harness_cli (Day 18-19) — 端到端

**server** (3 个模块 + lib.rs, ~660 行):

- `session_service.rs` (190 行): SessionServiceImpl (gRPC, 4 RPC: Create / Get / List / Close)
- `http.rs` (60 行): axum Router (GET /health, GET /version)
- 12 个单元测试 (server builder + agent + session + http)

**cli** (1 main.rs, 120 行):
