## 6 First-Party 插件实装 (本周全部完成)

### bash (Day 21, +301 行)
- **核心方法**: `run_command(ctx, cmd)` + `run_command_with_timeout(cmd, Duration)`
- **机制**: `tokio::process::Command` + `tokio::time::timeout`
- **typed key**: `MAX_RUNTIME_MS` (默认 30s, 业务方 set 覆盖)
- **跨平台**: sh -c (Unix) / cmd /C (Windows), test 用 echo/false/sleep 验证
- **5 测试**: echo / non-zero exit / stderr 捕获 / timeout / ctx 覆盖

### fs (Day 22, +263 行)
- **核心方法**: `read_file` / `write_file` / `list_dir` + `sanitize_path` + `check_allow_list`
- **机制**: `tokio::fs` + 路径白名单 (Vec<String> 前缀匹配)
- **typed key**: `READ_ALLOW_LIST` / `WRITE_ALLOW_LIST`
- **fail-closed**: 空白名单 = 拒绝所有 (跟 arch-map §6 sandbox 一致)
- **路径消毒**: 阻 ".." 穿越
- **6 测试**: in/out 白名单 / 空白名单拒绝 / 路径穿越 / 列目录

### web (Day 23, +289 行)
- **核心方法**: `http_get` / `http_post` (持 reqwest::Client, connection pool)
- **机制**: reqwest + URL 白名单 (前缀匹配) + ctx 超时
- **typed key**: `EGRESS_ALLOW_LIST` / `TIMEOUT_MS` (默认 30s)
- **跨 wiremock**: 5 测试用 wiremock 模拟 server (HTTP localhost, 不需 TLS)
- **5 测试**: get/post 成功 / 白名单外拒绝 / 空白名单拒绝 / 4xx 响应

### subagent (Day 24, ~170 行)
- **核心方法**: `spawn_agent(parent_ctx, message)`
- **机制**: `ctx.fork()` 派生 sub ctx (继承 parent service Arc 引用) + sub AgentLoop
- **typed key**: `MAX_DEPTH` (默认 3, 递归保护)
- **演示 cordis fork 实战**: 父 ctx 派生子 ctx, sub ctx 跑 sub agent
- **2 测试**: spawn 成功 / max depth 限制

### skill (Day 25, ~150 行)
- **核心方法**: `load_skill(ctx, name)` / `list_skills(ctx)`
- **机制**: `tokio::fs` + serde_yaml, 加载 `ctx.SKILLS_DIR/<name>.yaml`
- **typed key**: `SKILLS_DIR` (默认 "./skills")
- **Phase 1 简化**: 目录路径业务方 set, 不动态发现
- **3 测试**: 空目录 / 加载 / 不存在错误

### cordis (Day 25, ~115 行)
- **核心方法**: `inspect(ctx)` 反射 ctx 状态
- **返回**: CtxSnapshot { plugin_count, plugins, storage_keys, services, is_disposed }
- **typed key**: `INSPECT_DEPTH` (默认 2, 防递归自省)
- **meta 插件**: 让 model 能问"ctx 现在有什么"
- **2 测试**: 空 ctx / depth=0 拒绝

## 6 first-party 插件实装总览 (Phase 1 完成)

| 插件 | typed key | 核心方法 | 业务能力 |
|---|---|---|---|
| bash | `MAX_RUNTIME_MS` | `run_command` | 跑 shell 命令 (subprocess + timeout) |
| fs | `READ_ALLOW_LIST` / `WRITE_ALLOW_LIST` | `read_file` / `write_file` / `list_dir` | 文件系统沙箱 |
| web | `EGRESS_ALLOW_LIST` / `TIMEOUT_MS` | `http_get` / `http_post` | HTTP 客户端沙箱 |
| subagent | `MAX_DEPTH` | `spawn_agent` | 递归 agent (fork ctx) |
| skill | `SKILLS_DIR` | `load_skill` / `list_skills` | skill 描述加载 |
| cordis | `INSPECT_DEPTH` | `inspect` | ctx 反射 (meta 工具) |

**统一模式**:
1. typed key 在 ctx 存配置 (业务方 set 覆盖)
2. service 不存状态, 每次调用从 ctx 读 (跟 hello "活的 ctx" 一致)
3. fail-closed: 空白名单 / 默认值拒绝所有
4. 双重 impl cordis + seam trait (Phase 2 加 macro 自动派生)
