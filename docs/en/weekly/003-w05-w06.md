## 6 first-party plugins implemented (all done this week)

### bash (Day 21, +301 lines)

- **Core methods**: `run_command(ctx, cmd)` + `run_command_with_timeout(cmd, Duration)`
- **Mechanism**: `tokio::process::Command` + `tokio::time::timeout`
- **Typed key**: `MAX_RUNTIME_MS` (default 30s, business side sets to override)
- **Cross-platform**: `sh -c` (Unix) / `cmd /C` (Windows), tests use `echo`/`false`/`sleep` to verify
- **5 tests**: echo / non-zero exit / stderr capture / timeout / ctx override

### fs (Day 22, +263 lines)

- **Core methods**: `read_file` / `write_file` / `list_dir` + `sanitize_path` + `check_allow_list`
- **Mechanism**: `tokio::fs` + path whitelist (`Vec<String>` prefix match)
- **Typed keys**: `READ_ALLOW_LIST` / `WRITE_ALLOW_LIST`
- **Fail-closed**: empty whitelist = reject all (consistent with arch-map §6 sandbox)
- **Path sanitization**: block `..` traversal
- **6 tests**: in/out whitelist / empty whitelist rejection / path traversal / list directory

### web (Day 23, +289 lines)

- **Core methods**: `http_get` / `http_post` (holds `reqwest::Client`, connection pool)
- **Mechanism**: reqwest + URL whitelist (prefix match) + ctx timeout
- **Typed keys**: `EGRESS_ALLOW_LIST` / `TIMEOUT_MS` (default 30s)
- **Cross wiremock**: 5 tests use wiremock to mock server (HTTP localhost, no TLS needed)
- **5 tests**: get/post success / outside-whitelist rejection / empty-whitelist rejection / 4xx response

### subagent (Day 24, ~170 lines)

- **Core method**: `spawn_agent(parent_ctx, message)`
- **Mechanism**: `ctx.fork()` derives sub-ctx (inherits parent service `Arc` reference) + sub `AgentLoop`
- **Typed key**: `MAX_DEPTH` (default 3, recursion protection)
- **Demonstrates cordis fork in practice**: parent ctx spawns sub-ctx, sub-ctx runs sub-agent
- **2 tests**: spawn success / max depth limit

### skill (Day 25, ~150 lines)

- **Core methods**: `load_skill(ctx, name)` / `list_skills(ctx)`
- **Mechanism**: `tokio::fs` + `serde_yaml`, loads `ctx.SKILLS_DIR/<name>.yaml`
- **Typed key**: `SKILLS_DIR` (default `./skills`)
- **Phase 1 simplification**: directory path set by business side, not auto-discovered
- **3 tests**: empty directory / load / not-found error

### cordis (Day 25, ~115 lines)

- **Core method**: `inspect(ctx)` reflects ctx state
- **Returns**: `CtxSnapshot { plugin_count, plugins, storage_keys, services, is_disposed }`
- **Typed key**: `INSPECT_DEPTH` (default 2, anti-recursive introspection)
- **Meta plugin**: lets the model ask "what's in ctx right now"
- **2 tests**: empty ctx / `depth=0` rejection
